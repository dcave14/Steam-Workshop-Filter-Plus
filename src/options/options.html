Steam Workshop Filter Plus

Steam API key optional

Use your own key for batched metadata and dependency lookups. When configured, incomplete API data stays unverified until you retry.

The key stays in this browser’s local extension storage and is sent only to Steam’s API. It is never synced, included in a Workshop page, or shared with other users.

A saved key is never displayed. Leave the field blank to test the existing key.
